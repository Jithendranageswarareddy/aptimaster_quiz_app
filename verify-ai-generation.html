? Test 4: Check Vercel Logs

Manual verification of Vercel serverless function logs.

  1. Go to vercel.com/dashboard
  2. Select AptiMaster project
  3. Click Deployments → latest deployment
  4. Click Logs tab
  5. Search for [HANDLER] entries
  6. Look for message like: SUCCESS: OpenRouter returned 10 questions
ℹ️ Tip: If you see [HANDLER] OPENROUTER_API_KEY not set, the environment variable is missing in Vercel. Go to Settings → Environment Variables and add it.
